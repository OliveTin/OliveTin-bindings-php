# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| other   | :x:                |

## Reporting a Vulnerability

Please report security issues through **[GitHub private security advisories](https://docs.github.com/code-security/security-advisories)** for this repository when that is available; otherwise contact jamesread via https://jread.com . Avoid filing public issues for undisclosed vulnerabilities.
